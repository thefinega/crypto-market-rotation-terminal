## What It Does

Crypto Market Rotation Terminal is a Windows desktop market research tool for scanning public crypto market data across Binance, Bybit, and OKX.

It helps users compare:

- Market rotation
- Relative strength
- Rank changes
- Liquidity-adjusted performance
- Multi-period percentage changes
- Aggregated asset views
- Local watchlist and scan history

Main features:

- Scans public market data from Binance, Bybit, and OKX
- Supports quote markets such as USDT, USDC, and BTC when available
- Calculates 1D, 3D, 7D, 14D, 30D, 90D, 180D, and 365D performance metrics
- Provides Strength Score and Liquidity Adjusted Score
- Includes rank-change and rotation views
- Includes aggregated asset overview
- Supports local watchlist and scan history
- Supports CSV, JSON, and XLSX export
- Requires no exchange API key

## Installation Note

After purchase, two download options are included on Gumroad:

### 1. Windows Installer Version

Recommended for most users.

Download the installer ZIP, extract it, then run:

`market-rotation-setup.exe`

Follow the setup wizard and launch the app from the Start Menu or the desktop shortcut created by the installer.

### 2. Portable ZIP Version

Use this version if you prefer to run the app without installation.

Download the portable ZIP, extract it, then open the app folder and run:

`Crypto Market Rotation Terminal.exe`

For the portable version, do not move the `.exe` file outside the app folder. The `_internal` folder must stay next to the `.exe`.

If desktop access is needed, create a Windows shortcut instead of moving the `.exe` file.
