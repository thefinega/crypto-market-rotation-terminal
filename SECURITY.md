# Security

Do not open public issues for sensitive security matters.

Do not post:

- API keys
- Secrets
- Tokens
- Wallet information
- Exchange credentials
- Screenshots containing private information
- Logs with personal paths
- Account data
- Personal financial information

Crypto Market Rotation Terminal does not require API keys.

The product does not connect to user exchange accounts.

This GitHub repository does not distribute binaries, executable files, ZIP packages, source code, private data, or user data.

For product access, purchase, or download issues, use the official Gumroad page:
https://finega.gumroad.com/l/crypto-market-rotation-terminal
