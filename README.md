## What It Does

Crypto Market Rotation Terminal is a Windows desktop market research tool for scanning public crypto market data across Binance, Bybit, and OKX.

It helps users compare:

- Market rotation
- Relative strength
- Rank changes
- Liquidity-adjusted performance
- Multi-period percentage changes
- Aggregated asset views
- Local watchlist and scan history

Main features:

- Scans public market data from Binance, Bybit, and OKX
- Supports quote markets such as USDT, USDC, and BTC when available
- Calculates 1D, 3D, 7D, 14D, 30D, 90D, 180D, and 365D performance metrics
- Provides Strength Score and Liquidity Adjusted Score
- Includes rank-change and rotation views
- Includes aggregated asset overview
- Supports local watchlist and scan history
- Supports CSV, JSON, and XLSX export
- Requires no exchange API key

## Installation Note

After purchase, download the ZIP from Gumroad, extract it, and run the Windows application from the app folder.

Keep the `.exe` file and the `_internal` folder together. The application is distributed as a folder-based Windows app, not as a single standalone executable.

Do not move only the `.exe` file to another location. If desktop access is needed, create a Windows shortcut instead.
